# SocialGraphs_FinalProject

### Downloading the datasets
Run ```python dataDownload/crawler-musicBrainz.py --years 1970 1980``` (one ```songs_<year>.csv``` per year, resumable) and ```python dataDownload/download-Genius.py``` (keeps Genius songs from 1970-1980). The year range used by everything after the download is set by ```FIRST_YEAR, LAST_YEAR``` in ```dataCleaner/clean.py```. Each song gets its genres and its credits: ```instruments```, ```producers```, ```musicians```, ```vocals``` and record ```labels``` (empty where MusicBrainz has none). Every single credit, with MusicBrainz ids for building the collaboration graph, goes to ```credits_<year>.csv```. The credits phase needs one request per release, about 5.5 hours for 1970-1980; add ```--no-credits``` to skip it. Each run appends its endpoint, query, dates, request count, rate limit and resulting counts to ```collection_log.jsonl``` for the Methods section. Do note the crawler may get timed out if run too often as to not break rules regarding rate limits. Additionally the Genius dataset downloader needs at least 9gb free space on the disk.

### Cleaning and combining
Run ```dataCleaner/clean.py``` to clean both datasets (duplicates, version pages, non-song Genius pages), which writes ```songs_1970-1980_clean.csv``` and ```genius_1970-1980_clean.csv```. Then run ```dataCleaner/combine.py``` to attach Genius lyrics to the MusicBrainz songs, which writes ```songs_1970-1980_lyrics.csv```.

### Lyric-similarity graph and classifier
Run ```clustering/lyrics_network.py``` (about 20 minutes) for the song graph at k = 5, 10 and 20 and the artist graph, each as plain and mutual kNN, with Louvain over 10 seeds, NMI against genre, 1,000 genre shuffles and 10 degree-preserving rewirings as null models. The numbers go to ```clustering/lyrics_network_results.csv```. Add ```--balanced``` (about 10 minutes) to rerun the song graphs on 5 random samples with the same number of songs per genre, written to ```clustering/lyrics_network_balanced.csv```; the classifier runs the same balanced check. Run ```classification/classify_test.py``` for the genre-from-lyrics classifier. Both use the ```mb_label``` genres without rap and the word tokens in ```dataCleaner/text.py```.
